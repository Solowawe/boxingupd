СОРЕВНОВАНИЯ ПО БОКСУ
=====================

Распространение и запуск на другом компьютере.


Что в этой папке
----------------
server.py / app.py / database.py — бэкенд (Flask + SQLite)
index.html / login.html / app.js / style.css — фронтенд
boxing.db  — ваши данные (спортсмены, турниры, жеребьёвка, результаты)
requirements.txt — список зависимостей
run.bat    — запуск сервера
run.py     — альтернативный запускатель
setup.bat  — одноразовая установка на новом ПК


Как запустить на новом ПК (Windows)
------------------------------------
1. Установите Python 3.9+ с https://www.python.org
   (при установке отметьте галочку "Add Python to PATH").

2. Скопируйте ВСЮ эту папку на новый компьютер.

3. Дважды кликните setup.bat — он создаст окружение и поставит
   зависимости (нужен интернет, один раз). Обычно 1-2 минуты.

4. После этого запускайте run.bat (или). Откроется браузер:
   http://localhost:8080

5. Логин: admin   Пароль: admin
   (если не меняли через переменные окружения ADMIN_LOGIN / ADMIN_PASSWORD)


Примечания
----------
- Приложение работает полностью локально, интернет после установки не нужен.
- .venv сюда копировать не нужно — его создаёт setup.bat на этой машине.
- Все данные хранятся в boxing.db. Чтобы перенести наработки — копируйте
  этот файл. Можно делать резервные копии (папка backups создаётся сервером).
- Пароль и секретный ключ по умолчанию — для локальной работы.
  Для выкладки в интернет задайте переменные окружения:
    SECRET_KEY, ADMIN_PASSWORD, ADMIN_LOGIN.


Обновления приложения (кнопка «Проверить обновления»)
-----------------------------------------------------
Приложение умеет обновлять только файлы кода из Git-репозитория GitHub.

Для настройки задайте переменные окружения (в server.py или bat-файле):
    GITHUB_OWNER  — владелец репозитория (например, username)
    GITHUB_REPO   — имя репозитория
    GITHUB_BRANCH — ветка (по умолчанию main)

В корне репозитория должен лежать файл update-manifest.json:
{
  "version": "1.0.0",
  "files": ["app.js","index.html","style.css","login.html",
            "server.py","database.py","app.py","requirements.txt"]
}

Как работает:
- Нажимаете «Проверить обновления» — приложение сверяет версию в репозитории
  с локальной (файл local_version.txt, создаётся автоматически).
- Если версия новее — скачивает перечисленные файлы и заменяет локальные.
- ДАННЫЕ (boxing.db) файл НЕ обновляются — это ваши личные записи, их
  трогать нельзя. После обновления бэкенд-файлов перезапустите сервер.
